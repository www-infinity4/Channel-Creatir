BUILT-IN CONTRACT

Every generated channel starts with the network rules.

Seven days forwardCreatir requires enough unique full programs to fill every slot for the next seven days before deployment.
No recycled episodesThe same media ID cannot be scheduled twice inside the seven-day deck.
Full-program protectionShort clips, missing runtimes, duplicate IDs and broken sources are rejected instead of being used as filler.
Playback quarantineA source that errors or gets stuck at the beginning is quarantined instead of looping its first seconds.
Shared Omni Control remoteGenerated pages use Omni TV's reusable Channels control, backed by the central Control Phi channel registry instead of copying an old channel's remote.
Independent break timingThe shared channel policy provides deterministic channel-specific break offsets so future ad breaks do not all land together.
